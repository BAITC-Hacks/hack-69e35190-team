Источник требований: предоставленный «HackAlem AI_ Хакатон-задача_ умный подбор подрядчиков.md».

## Повторный аудит и исправления

Результаты исправления ошибок диалога, объяснений, регистра CSV и числовой валидации вынесены в [regressions.md](regressions.md). Разделы ниже описывают предыдущие этапы проверки и исторические замеры, а не итог повторного прогона.

## Дополнение: наглядная проверка критериев

- В интерфейсе есть запуск трёх независимых примеров с сохранением всех ответов, сравнение двух дат и повтор запроса. Счётчики категорий берутся из выбранного CSV.
- Сравнение дат вычисляется кодом и называет конкретные профили, занятые на другую дату. Отдельно обрабатывается выход свободного профиля из первой тройки вследствие сортировки.
- Под каждым ответом измеряется фактическое время в браузере. Полное ожидание одного AI-вызова ограничено 3 секундами; медленно поступающие байты не продлевают этот срок.
- Автотесты проверяют принадлежность конкретных цитат профилям после удаления имён, одинаковые цены при перезапуске и перестановке строк CSV, а также медленные локальные HTTP-ответы.

После дополнения `python -m unittest discover -s tests -v`: **33 теста прошли**. Внешние API для этой проверки не вызывались. В браузере проверены три примера (`matched`, `matched`, `no_matches`), сравнение 10/11 октября и совпадение порядка при повторе. Время локальных ответов в этой проверке — около 0,01 с; это измерение демо, а не гарантия времени внешнего сервиса. `node --check frontend/app.js` пройден, ошибок JavaScript в браузере не обнаружено.

## Обнаружено и исправлено

- В браузерном разборе отсутствовал синоним «фотосессия», а регулярное выражение длительности использовало ASCII-границу слова после кириллицы. Разбор перенесён в backend/chat.py; покрыт регрессионным тестом исходной фразы.
- В старом HTTP-обработчике неожиданные исключения могли оборвать соединение без JSON. Теперь возвращается HTTP 500 с идентификатором ошибки; frontend различает сетевую ошибку, тайм-аут и ошибку валидации. Конкретную историческую причину NetworkError со скриншота воспроизвести не удалось: прямой вызов исходного API уже отвечал корректно.
- Каталог и даты были привязаны к одному файлу/2026 году. Добавлены проверяемый импорт, версионирование, независимые календари и индексы, выбор каталога и сброс диалога.
- Неиспользуемая встроенная в HTML копия 66 профилей удалена. Единственный источник данных — выбранный CSV на сервере.

## Проверенные результаты

Исходная проверка до дополнения критериев: `python3 -m unittest discover -s tests -v`, 24 теста на Python 3.9.6. Проверяется и аварийный HTTP 500; запись ERROR в логах этого теста ожидаема. В тестах ключи не используются и внешних сетевых запросов нет. Отдельный тест не позволяет семантическому поиску предпочесть общую похвалу содержательной детали.

Живые OpenAI Embeddings: индекс построен, 277 фрагментов / 66 профилей. Отдельно проверен LLM-разбор словесной даты, суммы и длительности; нераспознанная категория остаётся уточнением, не угадывается. Строгие фильтры не зависят от доступности провайдера.

Живой API после индексации: ведущие 10 октября — [HK-88430, HK-29829, HK-27222]; 11 октября — [HK-44923, HK-27222, HK-44733]; флорист — [HK-39372]; флорист за рубежом — category_not_in_city. Замер четырёх запросов: 0.001–0.526 с, часть запросов с прогретым кэшем; это не нагрузочный SLA.

Исходная фраза со скриншота проверена в браузере: все поля, включая 3 часа, распознаны; no_matches, потому что у всех 8 фотографов цена выше 50 000 ₸. Для получения карточек нужно изменить условия, а не ослаблять фильтр.

## Границы готовности

- «Обучение» реализовано как пополнение поискового знания и вычисление эмбеддингов, не fine-tuning: это соответствует заданию.
- Произвольные таблицы другой предметной области требуют адаптера. Поддержан контракт подрядчиков с новыми значениями и периодами.
- Занятость подневная; время начала не оценивается. Нет бронирования, гарантии окончательной цены или реальной доступности.
- Сервер локальный, без пользователей и прав доступа; публичный запуск требует отдельного production-контура.
- LLM не обеспечивает универсального понимания речи; распознанные поля показываются пользователю. При ошибке провайдера работают локальные правила.
