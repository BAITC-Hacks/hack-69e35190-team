Как это работает внутри
  1. Каждое сообщение разбирается на поля: город, дата, тип мероприятия, категория, бюджет, опционально язык и длительность. Разбор — по ключевым словам и regex по датам/числам, без обращения к внешним сервисам, поэтому ответ мгновенный и повторяемый.
  2. Чего не хватает — спрашиваем по одному полю за раз (можно отвечать словом или кнопкой-подсказкой).
  3. Когда все обязательные поля собраны: пул = категория + город → жёсткие фильтры (занят на дату → дороже бюджета → не берёт формат, в этом порядке приоритета) → до 3 карточек, отранжированных по язык → длительность → цена → id.
  4. Три исхода различимы явно: подобрали / нет такой категории в городе / кандидаты есть, но никто не подходит — с разбивкой причин.
  5. Тот же запрос — тот же порядок. Можно уточнять на лету: «бюджет 500000», «давай на казахском» — пересчитает с учётом уже собранных полей.
